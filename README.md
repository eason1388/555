# 《修道與濟世》30 萬字書稿專案

這個儲存庫保存《修道與濟世》的完整續寫資料，可直接交給另一個 ChatGPT 或其他寫作者接續。

## 線上閱讀

完整書稿可在 [線上書庫](https://eason1388.github.io/555/) 閱讀，支援書籍切換、章節目錄、全文展開、關鍵字搜尋、字級與深色模式。亦可直接進入 [《修道與濟世》](https://eason1388.github.io/555/?book=xiudao)、[《陰陽相和》](https://eason1388.github.io/555/?book=yinyang)、[《黃帝內經輕鬆談》](https://eason1388.github.io/555/?book=qingsong) 或 [《黃帝內經實用生活篇》](https://eason1388.github.io/555/?book=life)。

## 新書計畫

[`黃帝內經養生書/`](黃帝內經養生書/) 收錄新作《陰陽相和：從〈黃帝內經〉讀懂養生之道》。全書以「養生，就是使陰陽隨時而和」為唯一理論；導論、七篇五十章、四項附錄與後記均已完成，共五十六個正文單元、200,310 字，並已合併為可連續閱讀的全書稿與[線上閱讀版](https://eason1388.github.io/555/?book=yinyang)。

[`黃帝內經輕鬆談/`](黃帝內經輕鬆談/) 收錄《黃帝內經輕鬆談》。全書從完整的人如何隨天地、時間與生活變化出發，廣泛講述《內經》的成書、身體觀、藏象、經絡、診察、病因、治療與日常；陰陽、男女關係與親密調和集中於單一專章。導讀、五十章、四項附錄與後記均已完成，並提供[線上閱讀版](https://eason1388.github.io/555/?book=qingsong)。

[`黃帝內經實用生活篇/`](黃帝內經實用生活篇/) 收錄新作《黃帝內經實用生活篇》。全書以每天的使用、收藏與補充為主線，將《內經》的整體眼光落實於作息、飲食、活動、情緒、關係、四季與生命階段。目前已完成全書目錄、導讀與第一篇六章，後續將依目錄持續完成約二十萬字，並同步更新[線上閱讀版](https://eason1388.github.io/555/?book=life)。

## 給接手者的第一句指令

請先完整閱讀 [`交接說明.md`](交接說明.md) 與 [`修道與濟世/全書章節規劃.md`](修道與濟世/全書章節規劃.md)，再依新版總綱持續回修及續寫，直到完成導論、60 章、6 項附錄、後記與 30 萬字正文。每章完成後直接繼續下一章，不要等待確認。

## 固定設定

- 書名：**《修道與濟世》**，不加副標題。
- 寫給一般讀者。
- 不介紹隨緣堂、網站、價目、接案或服務流程。
- 不寫成教義百科。
- 單一總綱：**道為本，德為承，氣為行，神為主，法為用，濟世為驗。**
- 正面呈現道法的威力、修行的重要及內修與外法的關係。
- 不用浮誇靈驗故事或現代物理術語假裝證明道法。
- 不虛構作者師承、法名、境界或真實案例。
